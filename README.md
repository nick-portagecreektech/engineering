# One-Shot Engineering Games

Two self-contained browser engineering games with a shared landing page.

- **SPAN** — Design and load-test a bridge using road, steel, and cable members.
- **FLOW//ONE** — Design and commission pump, fan, pipe, duct, valve, and filter systems.

## Play locally

Open `index.html` in a browser. No build process or dependencies are required.

## Publish with GitHub Pages

This repository includes `.github/workflows/pages.yml`.

1. Create a public GitHub repository and upload/push all files from this folder.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Open the **Actions** tab if needed and run the **Deploy static site to Pages** workflow.

The site will be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Files

- `index.html` — game selection landing page
- `span.html` — structural bridge game
- `flow-one.html` — fluid systems game
- `assets/` — preview images
- `.github/workflows/pages.yml` — GitHub Pages deployment
